INCLUSIVE BY DESIGN

Web Accessibility

Accessibility helps people with different abilities navigate, understand, and interact with websites.

Accessibility Best Practices

  • Use semantic HTML elements.
  • Add meaningful alternative text to images.
  • Maintain readable text and color contrast.
  • Support keyboard navigation and visible focus.
  • Label form controls clearly.
  • Use ARIA only when native HTML is insufficient.

Our Goal

Every visitor should be able to access the information they need, regardless of their device or abilities.
